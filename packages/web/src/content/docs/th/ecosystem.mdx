ชุดโครงการชุมชนที่สร้างขึ้นบน Selene

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Selene ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-selene](https://github.com/awesome-selene/awesome-selene) และ [selene.cafe](https://selene.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
